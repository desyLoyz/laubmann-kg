Description

Validation shapes for the Laubmann KG data graph (https://w3id.org/laubmann-kg/ontology 0.7.1). Run with inference=none: shapes target the concrete classes only (grouping superclasses are not materialised in the data). Every child node must carry dcterms:isPartOf (partonomy). Vocabulary/completeness checks are sh:Warning; datatype, cardinality and target-class checks sh:Violation.
