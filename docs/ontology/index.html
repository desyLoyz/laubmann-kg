Description

  • Project ontology for the HistOrniGraph knowledge graph built from the ornithological field diaries of the ornithologist Alfred Louis Laubmann (1886–1965; GND https://d-nb.info/gnd/1012394506; Bavaria, 1917–1965, 34 volumes). The HistOrniGraph project was funded by NFDI4Biodiversity. Two grouping classes structure the model: archival units (volume, page, entry, layout region — body-text regions and multimodal regions such as drawings, photographs, mounted objects and inserted texts) and entry records (what the extraction model reads out of one entry: observations as Darwin Core occurrences, travel events and their legs, weather reports); the partonomy between them is explicit (dcterms:isPartOf / hasPart). Taxa, places and persons are shared referents; habitats are NOT a class of this ontology but shared skos:Concepts of lkg:habitatScheme (see the controlled vocabularies), reached from an Observation via dwciri:habitat. Every link to an external authority — GBIF (taxa), EUNIS (habitats), GeoNames and Wikidata (places), Wikidata and GND (persons) — uses the same pattern (ontology 0.6.0): skos:exactMatch / skos:closeMatch / skos:broadMatch to the authority's IRI, which is described as a skos:Concept with skos:inScheme lkg:authority_, skos:notation and skos:prefLabel. Observations carry the spatial and temporal detail the text states (vantage point, microhabitat, flight height, own elevation, qualitative time of day, clock time, own date or date range). The ontology is Darwin-Core-first: wherever a dwc/dwciri, DCTERMS, PROV-O, SKOS, GeoSPARQL or schema.org term exists, the data graph uses that term alone; lkg: terms carry only project-specific meaning (record type, count qualifier, breeding evidence, movement, evidence kind, call type, entry kind, weather, travel, mention roles, spatial/temporal qualification, region kind). Controlled values are literals: each is the skos:notation of a concept in a SKOS concept scheme of the same namespace (the property's rdfs:seeAlso); the data graph is validated with SHACL.

  • Project ontology for the HistOrniGraph KG (diary entries, ornithological observations, travel, weather, persons, sources from the field journals of the ornithologist Alfred Louis Laubmann, GND https://d-nb.info/gnd/1012394506). Darwin-Core-first: standard terms are used wherever they exist; lkg: adds only project-specific terms. Grouping classes ArchivalUnit / EntryRecord plus an explicit dcterms partonomy. Habitats are skos:Concepts in lkg:habitatScheme (dwciri:habitat). External links (GBIF, EUNIS, GeoNames, Wikidata, GND) all use skos:exactMatch / closeMatch / broadMatch to an authority record in one of the lkg:authority_* schemes.

Class Definitions

Archival Unit c

IRI https://w3id.org/laubmann-kg/ontology#ArchivalUnit
Description

A unit of the digitised source: a diary volume, a scanned page, a dated entry or a layout region on a page (body text or multimodal). Grouping class only (not asserted as rdf:type in the data); the units are connected by dcterms:isPartOf (region → page → volume, entry → page). In Records in Contexts terms a volume is a Record and the others are parts of it.
Sub Class Of rico:RecordResource
Super Class Of
  • Diary Entry c
  • Diary Page c
  • Diary Volume c
  • Source Region c

Diary Entry c

IRI https://w3id.org/laubmann-kg/ontology#DiaryEntry
Description

The primary semantic unit: a dated, located entry written by the observer — the diarist's day. The node stands both for the text (a part of the volume) and for the day it records: it is the Darwin Core Event (dwc:eventDate, dwc:verbatimEventDate, dwc:verbatimLocality, dwc:fieldNotes; its IRI is the eventID of the DwC-A) and dcterms:hasPart its observations, travel events and weather report. dcterms:isPartOf its DiaryPage (or the volume when the page is unknown).

Entry Record c

IRI https://w3id.org/laubmann-kg/ontology#EntryRecord
Description

Anything the extraction model reads out of one diary entry: an Observation, a TravelEvent, a TravelLeg or a WeatherReport. Every entry record is prov:wasDerivedFrom exactly one DiaryEntry and prov:wasGeneratedBy the extraction run; it is dcterms:isPartOf that entry (a TravelLeg: of its TravelEvent). Grouping class only (not asserted as rdf:type in the data). Since 0.6.0 there is no separate 'record detail' level: vocalisations are properties of the Observation, travel legs are entry records.
Sub Class Of Entity c
Super Class Of
  • Observation c
  • Travel Event c
  • Travel Leg c
  • Weather Report c

Multimodal Region c

IRI https://w3id.org/laubmann-kg/ontology#MultimodalRegion
Description

A non-body-text region of a page that belongs to a diary entry: a drawing or sketch map, a photograph or postcard, a printed illustration, a mounted object (feathers, pressed leaves, labels) or an inserted text (newspaper clipping, typed report, letter, caption, list). Taken from the cleaned multimodal catalogue v2 (images and objects linked to a dated entry; duplicate scans of the same page removed) and from the text-inserts catalogue (paragraphs and lists judged relevant; marginal notes excluded). Carries dcterms:type (DCMI type), lkg:regionKind, dcterms:description (the layout model's description of an image, English) and lkg:visibleText (text on the region as transcribed); dcterms:isPartOf its DiaryPage, reached from its entry via lkg:hasMultimodalRegion. It is the entry it sits in, not the observations, that the region belongs to: the diarist placed it with the day's notes.
Sub Class Of Source Region c
In Domain Of

  • region kind dp
  • visible text dp
In Range Of has multimodal region op

Observation c

IRI https://w3id.org/laubmann-kg/ontology#Observation
Description

One taxon record read from a diary entry: a Darwin Core Occurrence (dwc:occurrenceStatus, dwc:individualCount, dwc:sex, dwc:lifeStage, dwc:eventDate, dwciri:recordedBy, dwciri:habitat …) plus the project detail (record type, count qualifier and range, breeding evidence, movement, evidence kinds, call type and transcription). An entry with several taxa has several Observations; the DiaryEntry is the event they belong to.

Person c

IRI https://w3id.org/laubmann-kg/ontology#Person
Description

A person mentioned in the diary (companion, source, collector, cited author) or recorded as observer (dwciri:recordedBy). The role is carried on the mention edge (sub-properties of lkg:mentionsPerson), not on the shared Person node. Name variants merged by entity resolution ("W. Wüst", "Wüst" → "Walter Wüst") are skos:altLabels. Linked persons carry skos:exactMatch / closeMatch to their Wikidata item and GND record (lkg:authority_wikidata, lkg:authority_gnd).
Sub Class Of schema:Person
In Range Of mentions person op

Place c

IRI https://w3id.org/laubmann-kg/ontology#Place
Description

A named location shared by every entry, record and journey that names it: a settlement, a named site or a region (lkg:placeKind). rdfs:label is the modern name, merged spellings are skos:altLabel; the wording of a particular use stays on that use (dwc:verbatimLocality of the entry or observation). Georeferenced places carry geo:lat/geo:long, dwc:decimalLatitude/Longitude, dwc:coordinateUncertaintyInMeters (centroid radius), a gsp:hasGeometry point, and link to their GeoNames feature and Wikidata item (skos:exactMatch / closeMatch, authority schemes lkg:authority_geonames, lkg:authority_wikidata); a stated elevation is dwc:minimumElevationInMeters / dwc:maximumElevationInMeters. Habitats are NOT places: they are skos:Concepts in lkg:habitatScheme.
Sub Class Of
  • Location c
  • gsp:Feature
  • geo1:SpatialThing
In Domain Of place kind dp
In Range Of
  • arrival place op
  • departure place op
  • entry place op
  • has locality op
  • observed at op
  • via place op

Source Region c

IRI https://w3id.org/laubmann-kg/ontology#SourceRegion
Description

A detected layout region on a scanned page (HistOrniGraph layout stage) that belongs to a diary entry; dcterms:isPartOf its DiaryPage. Asserted as lkg:SourceRegion for the body-text regions an entry's text was read from (an entry that runs over several pages has several), as lkg:MultimodalRegion for the pictorial, physical and inserted-text regions placed with the entry.
Sub Class Of
  • Archival Unit c
  • rico:RecordPart
In Range Of has source region op
Super Class Of Multimodal Region c

Taxon c

IRI https://w3id.org/laubmann-kg/ontology#Taxon
Description

A biological taxon (species, genus, family or informal group) observed or mentioned, keyed by the German vernacular name as the diarist wrote it (dwc:vernacularName; further spellings merged by entity resolution as skos:altLabel). Resolved names carry dwc:scientificName, dwc:taxonRank, the GBIF backbone link (skos:exactMatch / closeMatch / broadMatch to an authority record in lkg:authority_gbif; mirrored as the Darwin Core literal dwc:taxonID) and the GBIF higher classification (dwc:kingdom … dwc:genus).
Sub Class Of dwc:Taxon
In Domain Of
  • GBIF match type dp
  • is bird dp
  • match method dp
In Range Of observed taxon op

Travel Event c

IRI https://w3id.org/laubmann-kg/ontology#TravelEvent
Description

A journey of the diarist described in a diary entry, made of one or more TravelLegs (train, foot, boat …). Not a Darwin Core Event: the entry is the event, the journey a part of it.

Weather Report c

IRI https://w3id.org/laubmann-kg/ontology#WeatherReport

Weather as recorded in the diary entry (at most one report per entry). The verbatim wording (lkg:weatherVerbatim) is primary; structured values are optional normalisations and never unit-converted (historical entries may use Réaumur).
